## Что демонстрирует прототип

1. **Сценарий А** — объяснение комиссии с цитированием источников знаний (тариф + индивидуальный договор)
2. **Сценарий Б** — подготовка перевода → подтверждение клиентом (2FA) → исполнение
3. **Сценарий В** — регистрация спора (не гарантия возврата, требует проверки человеком)
4. **Идемпотентность** — повторный идентичный запрос возвращает то же действие (без дублирования)
5. **Эскалация** — передача диалога сотруднику с контекстом
6. **Аудит-лог** — все действия записываются с来源ом и результатом

## Ключевые архитектурные принципы (из ТЗ)

- ❌ Модель AI не может самостоятельно подтверждать переводы — требуется действие клиента
- ⚠️ Ошибки AI не должны приводить к несанкционированным операциям
- 🔄 Повторный запрос после тайм-аута не дублирует операцию (идемпотентность)
- 📋 Регистрация обращения ≠ одобрение возврата
- 🔍 Ответы подтверждаются источниками из базы знаний; если данных нет — не придумываем

# Назначение

Метод возвращает все действия клиента с их статусами для аудита и отображения в интерфейсе клиента.

# Алгоритм работы

1. Принять идентификатор клиента.
2. Проверить аутентификацию и право доступа к данным клиента.
3. Получить все действия клиента из хранилища.
4. Вернуть список действий с полными деталями (тип, статус, параметры, даты).

# Входные атрибуты

| Атрибут | Где передается | Тип данных | Описание |
|---------|---------------|------------|----------|
| client_id | path | string | Идентификатор клиента |

# Выходные атрибуты

| Атрибут | Тип данных | Описание |
|---------|------------|----------|
| actions | array[object] | Массив действий клиента |
| actions[].action_id | string | Идентификатор действия |
| actions[].action_type | string | Тип действия |
| actions[].status | string | Статус действия |
| actions[].created_at | string (date-time) | Дата создания |
| actions[].updated_at | string (date-time) | Дата последнего обновления |

# Пример запроса

```http
GET /clients/client-12345/actions
```

# Пример ответа

```json
{
  "actions": [
    {
      "action_id": "act-000001",
      "client_id": "client-12345",
      "action_type": "prepare_transfer",
      "status": "executed",
      "parameters": {
        "recipient": "Мама",
        "amount": 10000,
        "currency": "RUB"
      },
      "client_confirmed": true,
      "created_at": "2024-06-15T10:00:00Z",
      "updated_at": "2024-06-15T10:05:00Z"
    }
  ]
}
```

# Коды ответа

- `200` — список действий клиента
- `401` — не авторизован
- `404` — клиент не найден

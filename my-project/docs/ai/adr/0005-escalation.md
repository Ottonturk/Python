# ADR-0005: Передача сложных ситуаций сотруднику поддержки

## Статус
Принято

## Контекст
Сложные или нестандартные ситуации (например, спорная операция, требующая решения о возврате) должны передаваться сотруднику поддержки с сохранением контекста диалога.

## Рассмотренные альтернативы

### Вариант A: Переключение на отдельный чат с оператором
Клиент перенаправляется в новый чат, история не передаётся.

**Плюсы:** Простая реализация.
**Минусы:** Клиент повторяет информацию, потеря контекста, низкое качество обслуживания.

### Вариант B: Передача контекста в существующий канал — ВЫБРАН
История диалога с AI, контекст (карты, операции, подготовленные действия) передаются сотруднику в системе поддержки. Оператор видит всё, что уже feito.

**Плюсы:** Клиент не повторяется, оператор быстро вникает, бесшовный пользовательский опыт.
**Минусы:** Требуется интеграция с системой поддержки, хранение контекста диалога.

## Решение
Принят **Вариант B**:
- При запросе клиента на передачу сотруднику: полная история диалога, контекст, номер обращения (если создано) передаются в систему поддержки
- Оператор видит подготовленные AI действия и их статус
- После завершения диалога с оператором сессия ассистента может возобновиться с контекстом

## Последствия
- Необходима интеграция с системой тикетов/обращений поддержки
- Хранение контекста диалога (минимум до закрытия обращения)
- Обучение операторов работе с контекстом AI-диалогов

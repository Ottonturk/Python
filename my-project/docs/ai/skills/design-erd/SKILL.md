name: design-erd
description: Строит ER-диаграмму в PlantUML по текстовому ТЗ с описанием
  сущностей.
---

По входному ТЗ построй ER-диаграмму в PlantUML (`@startuml` ... `@enduml`):
- Сущности — через `entity <Имя> { ... }`, ровно те, что перечислены в ТЗ,
  с их атрибутами и типами. Первичный ключ помечай `<<PK>>`, внешний — `<<FK>>`,
  разделяя ключевые и обычные атрибуты строкой `--`.
- Связи между сущностями — в нотации "вороньей лапки" (`}o--||`, `}o--o{`
  и т.п.), по смыслу ТЗ.
- Связи подписывать не нужно, например "ссылается на"
- Не добавляй сущности, атрибуты или связи, которых нет в тексте ТЗ. Если тип
  данных явно не указан — выбери наиболее очевидный и не выдумывай
  ограничения, которых не было.
Сохрани результат в artifacts/erd/<имя-метода>.puml как чистый PlantUML-код
(без markdown-обертки и блоков ```), чтобы файл сразу рендерился расширением
PlantUML по своему расширению.

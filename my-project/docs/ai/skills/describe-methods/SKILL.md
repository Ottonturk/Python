---
name: describe-methods
description: Строит текстовое описание метода по шаблону (оглавление,
  назначение, алгоритм работы, входные/выходные атрибуты, примеры запроса и
  ответа, коды ответов) на основе текстового ТЗ.
---

По входному ТЗ построй описание метода по шаблону, строго в этом порядке
разделов:
1. Оглавление — ссылки на все разделы ниже.
2. Назначение — одно-два предложения о том, что делает метод и что возвращает.
3. Алгоритм работы — по шагам, в точности повторяя порядок действий из ТЗ
   (что метод проверяет, вызывает, создает), без добавления шагов, которых
   там нет.
4. Входные атрибуты — таблица: атрибут, где передается (body/path/query),
   тип данных, описание.
5. Выходные атрибуты — таблица: атрибут, тип данных, описание.
6. Пример запроса — пример тела/параметров запроса, собранный строго из
   входных атрибутов из раздела 4.
7. Пример ответа успешного и ошибочного — два примера: тело успешного ответа
   и тело хотя бы одного ошибочного ответа, если ошибки есть в ТЗ.
8. Коды ответа — список кодов, включая коды ошибок, если они описаны в ТЗ.

Не добавляй атрибуты, шаги алгоритма или коды ответа, которых нет в ТЗ.
Сохрани результат в artifacts/methods/<имя-метода>.md.
